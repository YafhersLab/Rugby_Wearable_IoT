# 🏉 Custom Wearable IoT Devices for Rugby Player Performance Monitoring

## 📌 Project Overview
This project involves the design and development of **custom wearable IoT devices** specifically tailored for **rugby player performance monitoring**. The devices are designed to be embedded directly into the players’ gear, enabling unobtrusive data collection during training and matches.

The system measures **player inclination** and **real-time GPS position**, transmitting data over the **cellular network** using the **MQTT protocol** to **AWS IoT**. The collected data is intended for further analysis and **machine learning applications**, enabling performance evaluation and behavioral insights.

This project demonstrates skills in:
- Wearable electronics design  
- Cellular IoT communication  
- Cloud integration with AWS IoT  
- Data acquisition for AI and analytics  

---

## 🎯 Motivation
The main motivation behind this project was to enable **data-driven analysis of rugby player performance** by collecting real-world movement and positioning data directly from athletes during gameplay.

By embedding custom electronics inside the players’ equipment, the system provides a scalable foundation for **artificial intelligence applications**, such as performance evaluation, behavior classification, and training optimization.

---

## 🧠 System Description
- Wearable devices are embedded inside the rugby player’s gear
- Sensors measure inclination and motion parameters
- GPS provides real-time player positioning
- Data is transmitted via cellular connectivity using MQTT
- AWS IoT serves as the cloud backend for data storage and processing
